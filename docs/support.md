## Email

**support@decnetgames.com** — the support address for MergeGuard and every Decnet Games product. When you write about a push-check finding or a resolution, include what Repo Health shows: its diagnostic log records every Git command MergeGuard has run, which makes a report answerable instead of speculative.

## Before you write

- [Troubleshooting]({{ site.baseurl }}/docs/troubleshooting/) covers the findings MergeGuard reports about itself: LFS missing, stale local refs, setup drift, and unpresentable content.
- [What v1 Is Not]({{ site.baseurl }}/docs/what-v1-is-not/) is the boundary list — if the thing you need is on it (a commit composer, hard locks, a non-Git VCS), it is a v1 boundary, not a bug.
