# MergeGuard-DOC

Documentation site source for **MergeGuard — Scene & Prefab Conflict Resolver for Unity + Git** by Decnet Games.

Built with Jekyll + [Just the Docs](https://just-the-docs.com/) (loaded via `remote_theme`) and published with GitHub Pages at:

**https://decnet-games.github.io/MergeGuard-DOC/**

## Layout

- `index.md` — Home
- `docs/` — Getting Started, Installation, Quick Start, The Home Window, One-Click Setup, The Conflict Resolver, Resolution Journal & Undo, Scene Locks & Declarations, Push Check, The Merge Drill, Team Lock Board (Studio), Push-Gate Reports & Check History (Studio), Team Policy (Studio), Settings, Editions (Standard vs Studio), What v1 Is Not, FAQ, Troubleshooting, Changelog, Support
- No `assets/` media yet: this tree was built before the product's Editor capture session (see PUSH-NOTE.md). Screenshots join the tree after captures exist — documentation never ships invented imagery.

MergeGuard itself is sold exclusively through the Unity Asset Store (publisher: Decnet Games). Nothing in this repository is the product — this repo is documentation only.
